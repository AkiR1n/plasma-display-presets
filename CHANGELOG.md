# Changelog

## 1.0.0 - 2026-04-08

- Initial public release.
- Added saving and restoring of display presets.
- Added memory mode for automatically recalling presets by exact monitor and connector combination.
- Added preset rename, overwrite, and delete actions.
- Added compact preset cards and per-preset rule management.
- Added Simplified Chinese, Traditional Chinese, and English support.
- Added local install, translation build, and release bundle scripts.
